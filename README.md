# Listifier
This package was made with the purpose of helping lists using recursion

# To install
in the **dist** folder there's a file with the **.whl** extention.<br>
open the terminal, type **pip install** or **pip3 install** and drag the **.whl** file.<br>
to install a newer version if still having VenomEngine installer, re-launch the command with **--force-reinstall at the end.<br>

# To import
you can use the **import Listifier** in any Python file you wanna it in. To optimize it, write **import Listifier as LF**<br>
 
# About the package
this is just a test of recursion with lists that began with an idea of making an extention for Python using recursion and the **random** module, for then expanding and becoming the current **Listifier**
